# 04 · 数据模型(简版)

> v0.2 数据模型, 6 个核心实体, 满足 MVP 即可。

---

## 0. 设计原则

- **最小够用**: 不做未来可能用不到的字段
- **家长 + 孩子 二角色**: 不做复杂的 4 角色权限
- **教研数据 + 用户数据 分离**: 教研数据可 YAML 维护, 用户数据存 PG

## 2. 核心实体

### 2.1 Family · 家庭

```python
class Family:
    id: UUID
    # 微信登录信息
    wx_openid: str              # 微信 openid(主键)
    wx_unionid: str | None      # 微信 unionid(可选)
    nickname: str                # 微信昵称
    avatar_url: str | None
    
    # 家长信息(可选)
    parent_name: str | None
    phone: str | None            # 加密
    
    # 系统
    created_at: datetime
    updated_at: datetime
    last_active_at: datetime | None
    
    # 偏好
    push_enabled: bool = True
    push_time: str = "19:00"     # 推送时间
    daily_limit_minutes: int = 30
    lock_at_night: bool = True
    lock_time: str = "21:00"
```

**说明**:
- 1 个家长账号 = 1 个 Family
- Family 可加 N 个孩子(自己家多个小孩)
- 暂时不支持多家长共同管理(后续可加"邀请配偶")

### 2.2 Child · 孩子档案

```python
class Child:
    id: UUID
    family_id: UUID             # 关联 Family
    
    # 基本信息
    name: str                    # 孩子姓名(或昵称)
    grade: int                   # 年级(1-6)
    class_name: str | None      # 班级(如"三年级二班")
    school_name: str | None     # 学校
    
    # 教材版本
    textbook_versions: dict      # { 'math': '沪教版', 'chinese': '统编版', ... }
    
    # 头像
    avatar: str | None
    
    # 系统
    created_at: datetime
    updated_at: datetime
    archived: bool = False       # 毕业/转学后归档
```

**说明**:
- 教材版本: 每科单独存(各科教材版本不同)
- 后续可加"入学年份"自动推算年级

### 2.3 KnowledgePoint · 知识点

```python
class KnowledgePoint:
    id: str                      # 如 "MATH-G3-CH2-K015"
    subject: str                 # math / chinese / english / ...
    grade: int
    chapter: str                 # 章节名
    name: str                    # 知识点名
    description: str             # 描述
    
    # 关联
    prerequisites: list[str]     # 前驱 ID 列表
    successors: list[str]        # 后继 ID 列表
    related: list[str]           # 相关 ID 列表
    
    # 元数据
    importance: int              # 1-5, 考试占比
    difficulty: int              # 1-5, 难度
    
    # 教学数据
    video_urls: list[str]        # 对应的 basic.sh.smartedu.cn 视频链接
    common_errors: list[str]     # 常见错题类型
    
    # 系统
    created_at: datetime
    updated_at: datetime
```

**说明**:
- 教研手工维护, 用 YAML 文件管理, CI 导入到 DB
- 视频链接是关键, 必须可点击跳到 basic.sh.smartedu.cn

### 2.4 ErrorItem · 错题

```python
class ErrorItem:
    id: UUID
    child_id: UUID
    knowledge_point_ids: list[str]  # 关联知识点(可多个)
    subject: str
    
    # 内容
    question_text: str           # 题目文字(OCR 或手输)
    question_image_url: str | None  # 拍照图片
    correct_answer: str          # 正确答案
    student_answer: str          # 学生答案
    
    # 错因
    error_type: str              # 7 类之一
    error_note: str | None       # 家长/孩子备注
    
    # 来源
    source: str                  # 'ocr' / 'manual' / 'parent_input'
    source_note: str | None      # 来自哪本作业/试卷
    
    # 复习状态
    status: str                  # 'new' / 'reviewing' / 'mastered' / 'archived'
    next_review_at: datetime | None
    review_count: int = 0
    last_reviewed_at: datetime | None
    last_review_correct: bool | None
    
    # 掌握度影响
    mastery_delta: float = 0.0   # 最近一次对掌握度的影响
    
    # 系统
    created_at: datetime
    created_by: str              # 'child' / 'parent'
    updated_at: datetime
    
    # 保留期
    retention_until: datetime    # 6 年后自动归档
```

**ErrorType 枚举**:
```python
ERROR_TYPES = [
    'CARELESS',          # 粗心/计算错
    'READING_WRONG',     # 审题错
    'METHOD_WRONG',      # 方法错
    'CONCEPT_CONFUSE',   # 概念混
    'KNOWLEDGE_GAP',     # 知识缺失
    'TIME_PRESSURE',     # 速度慢
    'OTHER',             # 其他
]
```

### 2.5 MasteryState · 知识点掌握度

```python
class MasteryState:
    id: UUID
    child_id: UUID
    knowledge_point_id: str
    
    # 核心
    correct_count: int = 0
    total_count: int = 0
    mastery: float = 0.0          # correct / total, [0, 1]
    
    # 错题统计
    error_count: int = 0
    recent_errors: int = 0        # 近 30 天
    
    # 时间
    last_practice_at: datetime | None
    first_practice_at: datetime | None
    
    updated_at: datetime
```

**简化算法**:
```python
# MVP 阶段: 简单计数
mastery = correct_count / total_count if total_count > 0 else 0

# 后期升级: 引入 BKT(贝叶斯知识追踪), 考虑时间衰减
```

### 2.6 CurriculumChange · 教材改版

```python
class CurriculumChange:
    id: UUID
    grade: int
    subject: str                 # 'math' / 'chinese' / ...
    version: str                 # '沪教版' / '统编版' / ...
    semester: str                # '2024-fall' / '2025-spring' / ...
    
    # 改了什么
    changes: list[dict]          # 详细改版内容
    
    # 来源
    source: str                  # 教研公告 / 网络报道 / 内部整理
    source_url: str | None
    verified: bool = False       # 是否已验证
    
    # 系统
    created_at: datetime
    updated_at: datetime
```

**changes 结构示例**:
```json
[
    {
        "chapter": "Unit 1",
        "type": "new",
        "summary": "新教材新增内容, 单词量 71→114",
        "key_points": ["词汇量增加 60%", "句型更复杂"]
    },
    {
        "chapter": "Unit 3",
        "type": "adjusted",
        "summary": "难度提升",
        "key_points": ["阅读量增加", "跨学科主题"]
    }
]
```

**说明**:
- 教研手工维护, 用 YAML
- 关键: **必须 verified=True** 才推送给用户, 未验证的标"待确认"

### 2.7 StudyRecord · 学习记录(可选)

```python
class StudyRecord:
    id: UUID
    child_id: UUID
    activity: str                # 'review' / 'preview' / 'ocr_upload' / ...
    duration_seconds: int
    knowledge_point_ids: list[str]
    error_item_id: UUID | None
    
    started_at: datetime
    ended_at: datetime | None
    device: str                  # 'ios' / 'android' / 'pc'
```

**说明**:
- 用于时长统计、报告
- MVP 阶段可简化, 不强求完整记录

### 2.8 ReviewQueue · 复习队列(独立表)

```python
class ReviewQueueItem:
    id: UUID
    error_item_id: UUID
    child_id: UUID
    scheduled_at: datetime
    completed_at: datetime | None
    result: str | None           # 'correct' / 'wrong' | None
    stage: int                   # 第几阶段(0=4h, 1=1d, ...)
    
    created_at: datetime
```

**说明**:
- 错题入库 → 创建 6 条 ReviewQueueItem(对应 6 个阶段)
- 每次孩子复习, 标记一条完成
- 答对 → 进入下一阶段
- 答错 → 删除未完成的, 重置阶段 0

### 2.9 PushRecord · 推送记录(审计)

```python
class PushRecord:
    id: UUID
    family_id: UUID
    child_id: UUID | None
    push_type: str               # 'daily' / 'weekly' / 'alert' / ...
    content_summary: str         # 推送内容摘要
    sent_at: datetime
    opened_at: datetime | None
    push_channel: str            # 'wechat_sub' / 'wechat_service'
```

**说明**:
- 用于: 推送频率限制 + 用户投诉排查

## 3. 用户体系设计

### 3.1 MVP 简化版(只有 2 角色)

| 角色 | 谁能做 | 不能做 |
|------|--------|--------|
| **家长** | 录入错题、看孩子档案、设提醒、看报告 | - |
| **孩子** | 看自己的错题本、复习、点"已掌握" | 改设置、删错题 |

### 3.2 鉴权
- 微信登录拿 openid
- 一个 openid = 一个 Family
- 一个 Family 可加 N 个孩子
- 简单 token(7 天有效), 存小程序 storage

### 3.3 后续可加(不急)
- 多家长共同管理(邀请配偶)
- 老师角色(看多个学生)
- 高级管理员(平台运营)

## 4. 教研数据 vs 用户数据

### 4.1 教研数据(只读)
- `KnowledgePoint`(知识点)
- `CurriculumChange`(教材改版)
- `video_urls`(视频链接映射)
- 存在代码仓库的 YAML 文件
- CI 时导入到 DB(可重建)

### 4.2 用户数据(读写)
- `Family`, `Child`, `ErrorItem`, `MasteryState`, `StudyRecord`, `ReviewQueue`, `PushRecord`
- 存 PostgreSQL
- 备份到 OSS

### 4.3 教研数据示例文件

`data/knowledge/math_g3.yaml`:
```yaml
- id: MATH-G3-CH1-K001
  grade: 3
  chapter: 第一章
  name: 两位数乘法
  description: 学习两位数乘一位数

  difficulty: 3
  prerequisites: [MATH-G2-CH3-K008]   # 一年级乘法
  successors: [MATH-G3-CH2-K012]      # 三位数乘法
  video_urls:
    - "https://basic.sh.smartedu.cn/..."
  common_errors:
    - 进位忘记
    - 数字错位
```

## 5. 索引设计

```sql
-- 常用查询索引
CREATE INDEX idx_error_child_subject ON error_items(child_id, subject);
CREATE INDEX idx_error_knowledge ON error_items USING gin(knowledge_point_ids);
CREATE INDEX idx_error_next_review ON error_items(child_id, next_review_at) WHERE status != 'mastered';
CREATE INDEX idx_review_queue_pending ON review_queue(scheduled_at) WHERE completed_at IS NULL;
CREATE INDEX idx_mastery_child ON mastery_states(child_id);
CREATE INDEX idx_curriculum_lookup ON curriculum_changes(grade, subject, version, semester);
```

## 6. 数据生命周期

| 数据 | 保留期 | 到期后 |
|------|--------|--------|
| 错题 | 6 年 | 加密归档 |
| 学习记录 | 3 年 | 聚合保留, 原文删 |
| 掌握度 | 毕业后 1 年 | 删 |
| 推送记录 | 1 年 | 删 |
| 审计日志 | 3 年 | 删(自用不需要 10 年) |
