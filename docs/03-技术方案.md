# 03 · 技术方案(2-3 周 MVP)

> v0.2 技术选型, 强调"轻量、可上线、不烧钱"。

---

## 0. 一句话原则

> **微信小程序 + Python 单体后端 + 阿里云免费额度, 2-3 周内出 MVP, 成本接近 0。**

---

## 1. 技术选型

| 组件 | 选型 | 理由 | 成本 |
|------|------|------|------|
| 前端 | **微信小程序原生** | 用户已有微信, 无需下载, 体验好, 审核快 | 免费 |
| 后端 | **Python FastAPI 单体** | AI 库丰富, 一个人能写, 单体能跑 | 0 |
| 数据库 | **PostgreSQL 14+** | 稳定, 免费, 关系强 | 0(本地)或 阿里云 RDS 入门级 100 元/月 |
| 存储 | **阿里云 OSS** | 错题图片 | 几元/月 |
| 缓存 | **内存 dict**(MVP) | 简单, 单体 | 0 |
| 消息队列 | **不用**(MVP) | 简单任务直接调 | 0 |
| OCR | **阿里云 OCR API** | 错题图片识别 | 几分/张 |
| 大模型 | **智谱 GLM-4 API** | 国产, 已备案, 价格低 | 1 元/百万 token |
| 部署 | **阿里云函数计算 FC + 阿里云 RDS** | 几乎免运维, 自动扩缩 | 试用免费 + 后续 100 元/月 |
| CI/CD | **手动**(MVP) | 一个人, 不需要 | 0 |
| 监控 | **Sentry + 微信报警**(后期) | 简单 | 0-100 元/月 |

**总成本**: MVP 阶段 0-100 元/月, 上线后 200-500 元/月(用完免费额度后)

## 4. 关键技术点

### 4.1 微信小程序登录

```python
# 1. 小程序调 wx.login() 拿到 code
# 2. POST /api/auth/wx-login { code: 'xxx' }
# 3. 后端拿 code 调微信接口换 openid + session_key
# 4. 后端生成自己的 token, 返回给小程序
# 5. 后续请求带这个 token
```

### 4.2 错题拍照

```python
# 1. 小程序 chooseImage, 上传到 /api/error/upload
# 2. 后端存到阿里云 OSS, 返回 url
# 3. 调阿里云 OCR 拿题目文本
# 4. 返回 { image_url, ocr_text, suggested_error_types }
# 5. 家长/孩子手填: 正确答案 + 错因 + 知识点
# 6. POST /api/error/commit 提交
```

### 4.3 智能归因(7 类)

MVP 阶段: **手动选 7 个错因之一**
后期: 调 GLM-4 看题目推荐错因

```python
async def suggest_error_type(question: str, correct: str, student: str) -> str:
    prompt = f"""
    分析下面这道错题的可能错因(只选一个):
    1. CARELESS(粗心/计算错)
    2. READING_WRONG(审题错)
    3. METHOD_WRONG(方法错)
    4. CONCEPT_CONFUSE(概念混)
    5. KNOWLEDGE_GAP(知识缺失)
    6. TIME_PRESSURE(速度)
    7. OTHER

    题目: {question}
    正确答案: {correct}
    学生答案: {student}

    只返回错因代码, 不要其他内容。
    """
    return await call_glm(prompt)
```

### 4.4 复习路径(简化版艾宾浩斯)

```python
REVIEW_INTERVALS = [
    timedelta(hours=4),
    timedelta(days=1),
    timedelta(days=3),
    timedelta(days=7),
    timedelta(days=14),
    timedelta(days=30),
]

async def schedule_review(error_id: str, child_id: str):
    for interval in REVIEW_INTERVALS:
        next_review = now() + interval
        await db.execute("""
            INSERT INTO review_queue (error_id, child_id, scheduled_at)
            VALUES ($1, $2, $3)
        """, error_id, child_id, next_review)
```

**调整规则**:
- 答对 → 进入下一阶段
- 答错 → 重置, 从第一个 4 小时重新开始
- 连续 3 次答对 → 间隔 ×1.5

### 4.5 21 点锁屏

**两种方案**:
1. **客户端检测**: 小程序在 onShow 时检查时间, ≥21:00 跳到锁定页
2. **服务端校验**: API 拒绝 21:00 后的写操作(防止绕过)

MVP 选方案 1(简单, 后期加方案 2)

### 4.6 推送

**MVP 阶段: 微信小程序订阅消息**
- 家长主动订阅(选择接收哪些)
- 后端触发推送(每天最多 1 条)

**后期**: 自建微信服务号 + 模板消息

## 11. 关键技术风险

| 风险 | 缓解 |
|------|------|
| 智谱 GLM API 限流 | 多 key 备选 + 本地缓存 |
| 阿里云 OCR 识别率低 | 后期训练专用模型(端侧 OCR 备选) |
| PG 单点故障 | 阿里云 RDS 自动备份, 灾难时恢复 |
| 微信小程序审核不通过 | 严格按规范, 不做违规内容 |
| 推送送达率低 | 关注订阅消息, 不做短信 |

## 14. 给开发者的快速上手

```bash
# 1. 克隆代码
git clone ...

# 2. 安装依赖
cd backend
pip install -r requirements.txt

# 3. 配置 .env
cp .env.example .env
# 编辑 .env 填入微信 appid/secret, 阿里云 key, 智谱 API key, PG url

# 4. 初始化数据库
alembic upgrade head
python scripts/seed_data.py  # 导入教研数据

# 5. 启动
uvicorn app.main:app --reload

# 6. 打开微信开发者工具, 导入 miniprogram/, 配置 appid
```

整个过程**应该 30 分钟内完成**。
