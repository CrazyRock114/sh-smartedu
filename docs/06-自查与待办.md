## 🛠️ 部署运维（石头用）

```bash
# 一键检查一切正常
./scripts/deploy/local-tunnel.sh status

# 重启 tunnel (URL 会变, 朋友链接要重发)
./scripts/deploy/local-tunnel.sh restart

# 当前 URL
./scripts/deploy/local-tunnel.sh url

# 停 tunnel
./scripts/deploy/local-tunnel.sh stop
```
