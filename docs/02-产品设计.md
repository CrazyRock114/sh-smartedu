## 模块 1 · 教材同步 + 改版追踪

### 解决痛点
P0 痛点 1.1: 教材改版看不懂

### 用户故事
> "我孩子下学期用新教材, 我想知道改了什么, 该重点抓什么。"

### 功能

#### 1.1 教材绑定
- 家长首次进入: 选择孩子的"年级 + 教材版本"
- 教材版本选项:
  - **语文**: 统编版(全国统一)
  - **数学**: 沪教版 / 人教版 / 北师大版(各区不同)
  - **英语**: 沪教版 / 人教 PEP 版 / 牛津上海版
  - **其他**: 自然、道德与法治等
- 数据来源: 维护一个"教材版本 + 学期"映射表

#### 1.2 改版追踪(2024-2026 重点)
- 维护一个"教材改版数据库":
  ```
  {
    grade: 3,
    subject: 'english',
    version: '人教PEP',
    semester: '2026-spring',
    changes: [
      { chapter: 'Unit 1', type: 'new', summary: '新增内容, 单词量 71→114' },
      { chapter: 'Unit 3', type: 'adjusted', summary: '难度提升, 句型更复杂' }
    ]
  }
  ```
- 自动按孩子的绑定显示: "三年级英语下学期, 新教材改了什么"
- 每周推送"本周要学的章节", 标注改版点

#### 1.3 本周章节推送
- 周日晚上自动推: "下周一 ~ 周五要学这些章节"
- 每个章节: 标题 + 重点 + 对应空中课堂/微课链接 + 改版标记
- 例: "周一 Unit 1 Hello 🆕 新教材, 单词量增加"

#### 1.4 章节内容来源
- **不存储** 教材原文(版权)
- 章节信息手工维护(教研数据)
- 微课/空中课堂链接直接跳到 basic.sh.smartedu.cn / 百视 TV

### 关键数据
- 改版数据库: 维护 1-6 年级, 4 个学科, 12 个学期 = ~300 条记录
- 链接维护: 每个章节对应 1-3 个视频 = ~600-1000 个链接

### 不做
- ❌ 不做教材原文存储(版权)
- ❌ 不做教材电子版展示(让用户去 basic.sh.smartedu.cn 看)
- ❌ 不做教材对比视图(简单文字说明就够)

## 模块 2 · 学情档案(轻量版)

### 解决痛点
P0 痛点 1.2: 家长看不懂孩子学什么

### 用户故事
> "我想知道孩子这周学了什么、掌握得怎么样、哪里薄弱。"

### 功能

#### 2.1 学科级仪表盘
- 顶部 4 张卡片(语数英 + 1 个其他):
  - 学科名 + 掌握度(0-100)
  - 趋势箭头(↑↓→)
  - 简要文字: "本周新学 8 个知识点, 掌握 6 个"
- 点击 → 进入学科详情

#### 2.2 知识点掌握度
- 学科详情页: 列表 + 图谱两种视图
- 每个知识点:
  - 名称(如"两位数乘法")
  - 掌握度颜色(红 0-40 / 黄 40-70 / 绿 70-100)
  - 上次接触时间
  - 错题数(关联到错题)
- 排序: 掌握度从低到高(优先看薄弱)

#### 2.3 错题热力图
- 视觉化展示: 哪个知识点错得最多
- 可选维度: 7 天 / 30 天 / 学期
- 点击某个知识点 → 看相关错题列表

#### 2.4 趋势曲线
- 过去 30/90 天:
  - 学习时长(每天)
  - 错题数(每天)
  - 掌握知识点数(累计)
- 不与"他人"对比(只与自己比)

### 关键算法(简化版)
- **掌握度**: 简单计数
  ```
  mastery = correct_count / total_count
  ```
  初期不用 BKT(数据太少, 用不上)
  后期数据多了再升级

- **错题热力**: 按知识点 group by

### 不做
- ❌ 不做"与同年级对比"(避免焦虑)
- ❌ 不做排名
- ❌ 不做"学习能力评估"类标签
- ❌ 不做预测考试分数

## 模块 3 · 错题本 + 智能归因

### 解决痛点
P0 痛点 1.3 + P1 痛点 2.1: 错题管理 + 知识关联

### 用户故事
> "孩子错题拍了照就完了, 没人看。希望系统能告诉我孩子哪里错了、为什么、该看哪个视频。"

### 功能

#### 3.1 错题录入(两种方式)

**A. 拍照 OCR(主要)**
- 拍一下 → 上传到 OSS → 调用 OCR API
- 自动识别题目(返回文字)
- 孩子/家长手填正确答案 + 孩子答案
- 可选: 拍照(留底)

**B. 手动录入(备选)**
- 文字框直接输入
- 适合不拍照的场景

#### 3.2 错因归因(7 类)
- 拍照后或录入后, 系统弹出选择:
  - 粗心(计算错、看错数字)
  - 审题错误(没看清楚题)
  - 方法错误(用错公式)
  - 概念混淆(A 概念和 B 概念混了)
  - 知识缺失(根本没学过)
  - 速度太慢(没做完)
  - 其他
- MVP 阶段: 手动选
- 后期: AI 辅助判断(看错题类型推荐错因)

#### 3.3 知识点匹配
- 错因选了后, 系统推荐关联知识点
- 家长/孩子选 1-3 个
- 后期: AI 自动从题目文本识别

#### 3.4 关联资源(核心价值)
- 错题入库后, 系统自动找:
  - basic.sh.smartedu.cn 上对应的微课/空中课堂
  - 之前学过的同知识点错题
- 展示: "看这个视频 + 这 2 道类似题"

#### 3.5 复习路径(艾宾浩斯简化版)
- 错题入库 → 自动加入复习队列
- 复习节奏(每个孩子可调):
  - 4 小时后
  - 1 天
  - 3 天
  - 7 天
  - 14 天
  - 30 天
- 每次复习: 看题 → 重做(可输入答案) → 标记"对/错"
- 答对: 掌握度提升, 跳到下一阶段
- 答错: 重置间隔, 重新开始

#### 3.6 错题本首页
- 列表: 错题卡片(题目预览 + 学科 + 错因 + 复习状态)
- 筛选: 待复习 / 已掌握 / 全部
- 排序: 最近 / 错题最多知识点

### 关键算法

**OCR**: 阿里云 OCR API(数学公式识别单独调)

**错因推荐**(后期):
- 简单规则: 答案与正确答案只是数字错位 → 粗心
- 答案与正确思路完全不同 → 概念混淆
- 调用 LLM 辅助判断

**复习间隔调整**:
- 默认节奏(上面那个)
- 孩子连续 3 次答对 → 间隔延长 50%
- 答错 → 立即重置

### 不做(硬红线)
- ❌ **不做"拍照直接给答案"** — 教育部 2021 明确禁止
- ❌ **不做"AI 老师讲题"** — 同上
- ❌ **不做答案分享社区** — 隐私 + 版权

### 怎么做才是合规的
- 错题拍下来, 系统**只做归因 + 推荐资源**
- 不直接说"答案是 X", 而是引导:"你看看题目要求什么运算?"
- 答案由孩子/家长**手填**或**重做**

## 模块 4 · 知识图谱(轻量)

### 解决痛点
P0 痛点 1.3: 学习割裂

### 用户故事
> "我想看到孩子现在学到哪了, 后面要学什么, 哪些跟这个有关。"

### 功能

#### 4.1 学科图谱
- 进入"数学 → 三年级", 看到:
  - 所有知识点的树状/网状图
  - 颜色编码: 红色未学过 / 黄色学习中 / 绿色已掌握
  - 当前正在学的章节高亮
- 节点可点击 → 详情页

#### 4.2 知识点详情
- 名称 + 描述
- 关联错题(如有)
- 推荐视频链接(basic.sh.smartedu.cn)
- "前驱知识" + "后继知识" 链接

#### 4.3 探索模式
- 家长视角: 看到全貌, 知道"这个学期要学这些"
- 孩子视角: 看到"我现在学到哪"

#### 4.4 节点规模
- MVP: 数学 1-3 年级, 约 100-200 节点
- 后续: 4-6 年级 + 语文 + 英语

### 数据来源
- 教研手工维护(参照 2022 课标)
- 后期: 教师社区贡献 + AI 半自动

### 关键算法
- 图可视化: 用 d3.js 或 vis.js(轻量级)
- 节点定位: 力导向布局 / 树状布局

### 不做
- ❌ 不做 500 节点规模(MVP 阶段做不到也不需要)
- ❌ 不做高级搜索(MVP 阶段)
- ❌ 不做"AI 自动扩展"(后期)

## 模块 5 · 学习计划 + 推送

### 解决痛点
P0 痛点 1.2 + P1 痛点 2.2: 家长不知情 + 沉迷

### 用户故事
> "我想知道孩子今天该学什么、学了多久。"

### 功能

#### 5.1 每日学习计划(自动生成)
- 每周日晚: 自动生成下周计划
- 基于:
  - 错题复习队列(优先级最高)
  - 本周要学的新章节
  - 孩子当前掌握度
- 每天推送: "今天建议: 复习 2 道错题 + 看 1 个新章节视频"

#### 5.2 推送通道
- 微信小程序订阅消息(用户主动订阅后)
- 微信服务号(后续)
- 不做短信(成本 + 打扰)

#### 5.3 推送频率限制
- 学习提醒: 每天最多 1 条
- 周报: 每周日 1 条
- 异常告警: 每月最多 3 条
- **总推送: 每月 ≤ 10 条**(避免打扰)

#### 5.4 21 点锁屏
- 21:00 后, 小程序进入"今日学习结束"页
- 不可绕过(避免孩子继续用)
- 家长可在设置中临时解锁 30 分钟

#### 5.5 时长统计
- 实时显示: 今日学习 25 分钟
- 每日上限: 小学 30-45 分钟(可调)
- 超过 30 分钟单次: 提示休息

#### 5.6 异常告警
- 连续 3 天没学习 → 推送提醒
- 错题扎堆(某知识点错 5+ 道) → 推送重点提示
- 学科掌握度大幅下降(>20%) → 推送

### 不做
- ❌ 不做"每日打卡"PK
- ❌ 不做"勋章"(避免功利化)
- ❌ 不做"学习积分"
- ❌ 不做"学习社群"
- ❌ 不做"广告推送"
- ❌ 不做"焦虑型提醒"(如"再不做就晚了")

## 跨模块设计

### 5.7 数据流
```
[孩子做作业] → 拍照错题
   ↓
[OCR + 错因归因] → ErrorItem 入库
   ↓
[知识点匹配] → 更新 MasteryState
   ↓
[推荐复习路径] → 加入复习队列
   ↓
[每周计划] → 自动生成
   ↓
[推送] → 微信订阅消息
```

### 5.8 适龄设计(简化)

| 年级 | 单次时长 | 每日上限 | 字号 | 颜色 |
|------|---------|---------|------|------|
| 1-2 | 10 分钟 | 20 分钟 | 大 | 鲜艳 |
| 3-4 | 15 分钟 | 30 分钟 | 中 | 适中 |
| 5-6 | 25 分钟 | 45 分钟 | 中 | 适中 |

### 5.9 离线支持
- 错题录入: 联网时同步
- 查看错题本: 离线可看
- 视频: 依赖网络(不缓存, 跳到外部链接)

### 5.10 性能
- 错题拍照 → 入库 → 归因: < 5 秒
- 仪表盘加载: < 1.5 秒
- 报告生成: < 3 秒

## 给开发者(石头本人)的接口

### 1. 数据库表
- `families` 家庭
- `children` 孩子
- `error_items` 错题
- `knowledge_points` 知识点
- `study_records` 学习记录
- `curriculum_changes` 教材改版
- `push_records` 推送记录

### 2. API
- `POST /api/errors` 上传错题
- `GET /api/dashboard/:childId` 获取仪表盘
- `GET /api/knowledge/:subjectId` 获取知识图谱
- `GET /api/curriculum/:grade/:subject` 获取教材改版
- `POST /api/push/subscribe` 订阅推送

### 3. 小程序页面
- `index` 家长首页(3 张卡片)
- `child/:id` 孩子详情
- `error/list` 错题本
- `error/new` 新增错题
- `knowledge/:subject` 知识图谱
- `settings` 设置

### 4. 任务
- `weekly_plan_generator` 周日晚自动跑
- `21_lock` 21:00 自动锁
- `recalc_mastery` 重算掌握度(每次错题/复习后)

## 边界与例外

### 哪些情况不处理
- 孩子不愿意用 → 不强求, 父母自己用着看也 OK
- 错题太多录不完 → 优先录"反复错"的
- 知识点图谱不全 → 用文字描述替代
- 教材改版数据库滞后 → 标注"待确认", 不误导

### 灰度
- MVP 阶段: 自家孩子 + 朋友家 5-10 个
- 验证后再扩散
